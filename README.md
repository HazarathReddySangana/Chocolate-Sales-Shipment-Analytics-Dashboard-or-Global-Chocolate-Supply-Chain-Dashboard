# Chocolate-Sales-Shipment-Analytics-Dashboard-or-Global-Chocolate-Supply-Chain-Dashboard
Developed an interactive Power BI dashboard to analyze chocolate product sales, shipment performance, regional distribution, salesperson performance, order status, revenue trends, and product-wise insights for business decision-making.



1. Requirement Analysis
Identified the business problem.
Determined the KPIs and metrics needed for decision-making.
2. Data Collection
Gathered data from Excel/CSV/Database sources.
Verified data quality before importing.
3. Data Cleaning
Removed duplicate records.
Handled missing values.
Corrected data types using Power Query.
4. Data Modeling
Created relationships between tables.
Designed a proper data model for analysis.
5. DAX Calculations
Created measures and calculated columns.
Developed KPIs such as totals, averages, percentages, and trends.
6. Dashboard Development
Added:
Line Charts
Bar Charts
Pie Charts
Cards
Slicers
Tables
7. Testing
Validated calculations with source data.
Checked filter interactions and report accuracy.
